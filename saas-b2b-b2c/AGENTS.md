# AGENTS.md — Контекст проекта

## Проект
SaaS-платформа для франшиз: бэкенд на Go (Gin/GORM) + фронтенд на Next.js (Ant Design/RTK Query).

## Конвенции
- Телефон в БД: каноничный `+79991234567`, в UI: `formatPhone()` из `@/utils/phone`
- Салоны работают 7 дней в неделю (включая выходные и праздники)
- `salon_manager` = продавец (НЕ `sales_rep`)
- Маржа по умолчанию: 37%. По категориям: Кухни=35, Мягкая=40, Корпусная=30, Матрасы=45
- Договор автосоздаётся при конверсии лида→sale: `MarginPercent=37`, `PaymentDate=+7д`
- Предупреждения о просрочках: НЕ сохраняются в БД, передаются как `overdue_warnings[]` в ответе API
